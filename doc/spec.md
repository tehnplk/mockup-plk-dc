# Plk SRRT Network Operating System  
# ระบบปฏิบัติการเครือข่ายเฝ้าระวังสอบเคลื่อนที่เร็ว จังหวัดพิษณุโลก

##  UX/UI spec
### โมดูลของหน่วยบริการ
    - Agent แจ้งเตือนผู้รับผิดชอบงานสอบสวนโรคว่าแพทย์ Dx รหัสโรคที่ผู้รับผิดชอบเลือกไว้ มีหน้าจอคัดเข้า ICd10 
    - ดึงข้อมูลอัตโนมัติจาก HIS  ผู้ใช้เติมข้อมูลบางส่วน (Option)
    - บันทึกข้อมูลสอบสวนโรค
    - แจ้งเคส  Line OA หมอพร้อม Flex message จาก หน่วยบริการไป ไป ทีม SRRT/CDCU
    - รับเคส กดรับจาก dashbord กลาง หรือ Line OA หมอพร้อม Flex message
    - แจ้งเตือนด้วย Line OA หมอพร้อม Flex message ไปให้ประชาชนที่คัดเข้า
    - ยื่นคำร้องขออนุมัติตัดเคสออกจากพิ้นที่ไปยัง Admin
    - แผนที่การระบาด (GIS)
    - ระบบวิเคราะห์ข้อมูลด้วย AI
    - ระบบผลิตสื่อประชาสัมพันธ์
    - ระบบแจ้งข่าวประชาสัมพันธ์ประชาชนในพื้นที่ระบาดด้วยไลน์หมอพร้อม
    - ระบบติดตามพฤติกรรมสุขภาพต่อการดูแลตนเองจากการระบาดของประชาชน
    - ระบบจัดเก็บค้นคืนเอกสาร
    
### โมดูลทีม SRRT / CDCU
    - รับเคส กดรับจาก dashbord กลาง หรือ Line OA หมอพร้อม Flex message
    - บันทึกการสอบสวน และควบคุมโรค ภาคสนาม


### โมดูลระบบบัญชาการระดับจังหวัด
    - Dashbord กลาง
    - สถานะการสอบสวนควคุมโรครายเคส
    - ระบบติดตามความก้าวหน้ารายเคส
    - ระบบกำหนดกติกาด้วย Admin
    - ระบบแผนภูมิ
    - ระบบแผนที่
    - รับคำร้อง/อนุมัติตัดเคสออก
    - ระบบสำรวจ/จัดสรรทรัพยกรควบคุมโรค
    - อื่นๆที่ใช้สนับสนุนการตัดสินใจ
