# Operating System Platform  สอบสวนควบคุมโรค สำนักงานสาธารณสุขจังหวัดพิษณุโลก


## 1) ระบบงานที่โรงพยาบาล (รองรับรัฐและเอกชน)
### device
- Webapp Desktop และ  Web Mobile
### feature
- เลือกประเภทโรคที่จะทำข้อมูล
- ดึงข้อมูลอัตโนมัติจาก HIS  ผู้ใช้เติมข้อมูลบางส่วน (Option)
- สรุปการสนทนากับผู้ป่วยด้วย voice เป็น text
- ระบบจัดเก็บค้นคืนเอกสาร
- push ข้อมูลเข้า Dashbord กลางของจังหวัด
- ส่ง flex message เข้าไลน์หมอพร้อมของทีมเจ้าหน้าที่ที่คัดเลือกไว้


## 2) ระบบงานภาคสนามสำหรับทีมสอบสวนควบคุมโรค

- Webapp Desktop และ  Web Mobile 
### feature
- กดรับเคสจากโรงพยาบาล
- บันทึกข้อมูลสอบสวนควบคุมโรค
- ถ่ายรูป
- เก็บพิกัด
- อัด voice

## 3) ระบบงานของหน่วยบริการเจ้าของพื้นที่ (รพ.สต.)
### device
- Webapp Desktop และ  Web Mobile
### feature
- บันทึกข้อมูลสอบสวนควบคุมโรค
- ยื่นคำร้องตัดเคสออก
- แผนที่การระบาด
- ระบบวิเคราะห์ข้อมูลด้วย AI
- ระบบผลิตสื่อประชาสัมพันธ์
- ระบบแจ้งข่าวประชาสัมพันธ์ประชาชนในพื้นที่ระบาดด้วยไลน์หมอพร้อม
- ระบบติดตามพฤติกรรมสุขภาพต่อการดูแลตนเองจากการระบาดของประชาชน
- ระบบจัดเก็บค้นคืนเอกสาร
