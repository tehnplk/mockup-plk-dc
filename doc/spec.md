# Plk SRRT Network Operating System  
# ระบบปฏิบัติการเครือข่ายเฝ้าระวังสอบเคลื่อนที่เร็ว จังหวัดพิษณุโลก

##  UX/UI spec
### โมดูลของหน่วยบริการ
    1) feature สอบสวนผู้ป่วยใน รพ. และแจ้งเครือข่าย SRRT / CDCU อำเภอ
        - Agent แจ้งเตือนผู้รับผิดชอบงานสอบสวนโรคว่าแพทย์วินิจฉัย รหัสโรคที่ผู้รับผิดชอบเลือกไว้ มีหน้าจอคัดเคสเข้าด้วย ICD10 ที่ตั้งไว้ 
        - ดึงข้อมูลอัตโนมัติจาก HIS  ผู้ใช้เติมข้อมูลบางส่วน (Option)
        - บันทึกข้อมูลสอบสวนโรค
        - แจ้งเคสด้วย  Line OA หมอพร้อม Flex message จาก หน่วยบริการไปยังทีม SRRT/CDCU
        - ทะเบียนแจ้งเคส และผลการตอบกลับ
    
    2) feature ในฐานะเจ้าของพื้นที่ ต้องรับแจ้งเคสจาก รพ.อื่นๆได้ และดำเนินการสอบสวนควบคุมโรคในเขตพื้นที่รับผิดชอบ
        - กดรับเคสจาก dashbord กลาง หรือ Line OA หมอพร้อม Flex message
        - แจ้งเตือนการระบาดด้วย Line OA หมอพร้อม Flex message ไปให้ประชาชนในเขตรับผิดชอบที่คัดเข้า
    
    3) feature สำหรับจัดการข้อมูลในพื้นที่
        - ยื่นคำร้องขออนุมัติตัดเคสออกจากพิ้นที่ไปยังสสจ.พิษณุโลก
        - แผนที่การระบาด (GIS) 
        - ระบบวิเคราะห์ข้อมูล
        - ระบบผลิตสื่อประชาสัมพันธ์
        - ระบบแจ้งข่าวประชาสัมพันธ์ประชาชนในพื้นที่ระบาดด้วยไลน์หมอพร้อม
        - ระบบติดตามพฤติกรรมสุขภาพต่อการดูแลตนเองจากการระบาดของประชาชน
        - ระบบจัดเก็บค้นคืนเอกสารสอบสวนควบคุมโรค
        - ระบบ  Assistant ด้วย AI
    
### โมดูลทีม SRRT / CDCU
    - กดรับเคสจาก dashbord กลาง หรือ Line OA หมอพร้อม Flex message
    - บันทึกการสอบสวน และควบคุมโรค ภาคสนาม


### โมดูลระบบบัญชาการระดับจังหวัด
    - Dashbord กลาง
    - สถานะการสอบสวนควบคุมโรครายเคส
    - ระบบติดตามความก้าวหน้ารายเคส
    - ระบบกำหนดกติกาด้วย Admin
    - ระบบแผนภูมิ
    - ระบบแผนที่ GIS
    - รับคำร้อง/อนุมัติตัดเคสออก
    - ระบบสำรวจ/จัดสรรทรัพยกรควบคุมโรค
    - อื่นๆที่ใช้สนับสนุนการตัดสินใจ
